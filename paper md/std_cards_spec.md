# 標日卡片產出規格（v5.0）

輸入：`std_extracted.json`（PDF 座標抽取，**含 OCR 錯誤，必須修正**）
輸出：`std_cards/L{N}.json`（N=課號，一課一檔）

## OCR 修正原則（最重要）

抽取文字來自 OCR 文字層，常見錯誤：`日禾人`→`日本人`、`吉亩`→`吉田`、`抑うごくじん`→`ちゅうごくじん`、`昨百`→`昨日`。
你是日語專家，《新版中日交流標準日本語 初級上》是標準教材：**以抽取文字為證據，用你對教材與 N5 日語的知識重建正確的句子與讀音**。
無法確信的字詞：照最合理修正寫出，並在該卡加 `"review": "原文『…』不確定"`。
整行是亂碼、頁眉、練習題指示（如「仿照例句替换画线部分」）→ 直接捨棄。

## 讀音格式（沿用 App 既有格式，嚴格遵守）

- `ruby`：漢字段落後接 `|かな`，前後以半形空白分隔。例：`昨日|きのう デパートへ 行|い って、 買|か い 物|もの しました`
- 純假名詞 ruby = 原文。`reading`：整句/整詞的純假名（不含漢字、不含 `|`）。
- 驗證規則：ruby 去掉 `|かな` 與空白後必須等於 `jp` 去空白；reading 必須是純假名＋ー〜。

## 卡片 schema

```json
// 單字卡（來自 vocab；entry 形如 "社員（职员）"，中文釋義轉成台灣繁體用語）
{"id":"s_0101","jp":"社員","ruby":"社員|しゃいん","reading":"しゃいん","meaning":"（公司）職員",
 "type":"word","chapter":"標日 第1單元","sec":"第1課 李さんは中国人です","sub":"生词",
 "sentence":"李|り さんは JC 企画|きかく の 社員|しゃいん です","sentenceMeaning":"小李是JC策劃公司的職員"}

// 例句卡(基本課文每句必收；應用課文挑 6-10 句自然、可複用的對話句)
{"id":"s_0120","jp":"李さんは中国人です。","ruby":"李|り さんは 中国人|ちゅうごくじん です。",
 "reading":"りさんはちゅうごくじんです","meaning":"小李是中國人。",
 "type":"sentence","chapter":"標日 第1單元","sec":"第1課 李さんは中国人です","sub":"基本課文","grammar":["g_0101"]}

// 文法卡（每課 4-6 個，pattern 依下方「文法點對照表」，不可自創或遺漏）
{"id":"g_0101","pattern":"〜は〜です","title":"「〜是〜」判斷句",
 "explain":"「は」提示主題，唸作「わ」。相當於中文「〜是〜」。",
 "type":"grammar","chapter":"標日 第1單元","sec":"第1課 李さんは中国人です",
 "examples":[{"jp":"わたしは日本人です。","ruby":"わたしは 日本人|にほんじん です。","cn":"我是日本人。"}]}
```

- id 規則：單字/例句卡 `s_{課號2位}{流水2位}`（如 s_0101…s_0135）；文法卡 `g_{課號2位}{流水2位}`。
- `chapter` 固定六選一：`標日 第1單元`(L1-4)、`標日 第2單元`(L5-8)、`標日 第3單元`(L9-12)、`標日 第4單元`(L13-16)、`標日 第5單元`(L17-20)、`標日 第6單元`(L21-24)。
- `sec` 固定 `第N課 課名`（課名見文法點對照表）。
- meaning／sentenceMeaning／explain／title 一律台灣繁體中文。
- 單字卡盡量配一個該課課文出現過的 sentence；沒有就省略欄位。
- 例句卡 `grammar`：該句用到的本課文法卡 id 陣列（跨課不用標）。

## 文法點對照表（權威清單，每課照此產出文法卡）

L1 李さんは中国人です：〜は〜です／〜は〜ではありません／〜は〜ですか（含應答はい・いいえ・ちがいます）／〜の〜［從屬・屬性］
L2 これは本です：これ/それ/あれは〜です／この/その/あの〜は〜です／だれですか・何ですか／〜の［所屬］／どれ・どの〜
L3 ここはデパートです：ここ/そこ/あそこは〜です／こちら/そちら/あちら/どちら（禮貌指示）／〜はどこですか／〜も〜です／〜はいくらですか
L4 部屋に机といすがあります：〜に〜があります・います／〜は〜にあります・います／上/下/前/後ろ/隣/中/外（方位詞）／〜と〜［並列］／〜ね［確認］
L5 森さんは7時に起きます：動詞ます形（〜ます/ません/ました/ませんでした）／今〜時〜分です／〜に〜［時間點］／〜から〜まで／〜は〜［對比］
L6 吉田さんは来月中国へ行きます：〜へ〜［移動方向］／〜から［起點］／〜で［交通工具］／助詞疊用（に/で/へ/から+は）
L7 李さんは毎日コーヒーを飲みます：〜を〜［賓語］／〜で〜［動作場所］／〜か〜［選擇］／〜をください
L8 李さんは日本語で手紙を書きます：〜で［工具・手段］／〜に〜をあげます／〜に〜をもらいます／もう・まだ／〜よ［提醒］
L9 四川料理は辛いです：一類形容詞（〜いです/くないです/かったです/くなかったです）／一類形容詞+名詞／あまり〜（否定）
L10 京都の紅葉は有名です：二類形容詞（〜です/ではありません/でした）／二類形容詞+名詞／どんな〜／〜はどうですか／そして・でも
L11 小野さんは歌が好きです：〜は〜が好きです・嫌いです／〜は〜が上手です・下手です／〜は〜が分かります・できます／〜や〜［列舉］／〜から［原因］・どうしてですか
L12 李さんは森さんより若いです：〜は〜より〜です／〜と〜とどちらが〜ですか／〜でいちばん〜は〜です／〜ほど〜ないです／〜の中で〜がいちばん〜です
L13 机の上に本が3冊あります：數量詞+動詞／数量+で／〜へ〜に行きます［目的］／〜くらい・ぐらい／ます形（整理）
L14 昨日デパートへ行って,買い物しました：動詞て形（變化規則）／〜て〜［相繼發生］／〜てから〜／〜てください／〜を［經過・離開］
L15 小野さんは今新聞を読んでいます：〜ています［正在進行］／〜てもいいです／〜てはいけません／に・へ的區別
L16 ホテルの部屋は広くて明るいです：〜て・〜で［並列］／〜ています［結果狀態］／〜は〜があります［擁有］／まだ〜ています（否定：まだ〜ていません）
L17 わたしは新しい洋服が欲しいです：〜が欲しいです／〜たいです／〜ませんか［邀請］／〜ましょう／疑問詞+でも
L18 携帯電話はとても小さくなりました：〜くなります・〜になります［變化］／〜くします・〜にします［使變化・決定］／〜ほうがいいです
L19 部屋のかぎを忘れないでください：動詞ない形／〜ないでください／〜なくてもいいです／〜なければなりません／〜が〜［主語］
L20 スミスさんはピアノを弾くことができます：動詞基本形／〜ことができます／〜は〜ことです［愛好］／〜前に〜／疑問詞+か／〜よね
L21 わたしはすき焼きを食べたことがあります：動詞た形／〜たことがあります／〜た後で〜／〜たほうがいいです／〜ましょうか［提議］
L22 森さんは毎晩テレビを見る：簡體形（動詞・一類形容詞・二類形容詞・名詞）／敬體與簡體的使用場合／〜かな／〜けど
L23 休みの日,散歩したり買い物に行ったりします：〜たり〜たりします／〜かったり〜かったりです／〜かどうか〜／疑問詞小句+か
L24 李さんはもうすぐ来ると思います：〜と思います／〜と言いました／〜のです・んです／どうして〜のですか／〜が,〜［鋪墊］

## 數量指引（每課）

- 文法卡：對照表列幾個就幾個（4-6）
- 例句卡：基本課文全收（约4句）＋應用課文精選 6-10 句
- 單字卡：vocab 裡合法條目全收（過濾：`詞（中文）`格式或純詞條；捨棄含「。」「►」「——」的句子、頁碼、亂碼）
